# Credits

This branch (`integ/community-2026-10`) is [Niko1221/Strata](https://github.com/Niko1221/Strata) main `cbfd5b92` plus our RDNA4 (gfx1201/RDNA4, AMD Radeon AI PRO R9700) and DFlash2 work, plus **133 community pull requests** merged in 17 batches.

Authorship is preserved in git: every community commit keeps its original author (`git log --format="%an <%ae>"`); merge commits record the PR in the subject line (`merge #N (title) — integ batch K`), and commits that could not be merged as a branch (unrelated history, re-authored fixes) carry a `(cherry picked from commit ...)` trailer. Integration fixes by the repo maintainer are prefixed `integ:`.
